- Listing state: downloadable and marked animated

## Import convention

Download the model from Sketchfab using its normal Download 3D Model control. Extract the archive into this directory. Prefer the glTF download and keep its original companion `.bin` and texture files intact.

TankWall's runtime adapter looks for these scene candidates, in order:

1. `res://assets/models/bluemesh_betta/scene.gltf`
2. `res://assets/models/bluemesh_betta/scene.glb`
3. `res://assets/models/bluemesh_betta/betta_splendens.gltf`
4. `res://assets/models/bluemesh_betta/betta_splendens.glb`

Do not remove this attribution when distributing builds that include the BlueMesh model. The model itself is not committed here until obtained through Sketchfab's normal download flow.
